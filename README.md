# Сайт стоматологии Юлии и Тихона

Сайт с онлайн-записью по свободным слотам и кабинетом для персонала.
Приём ведётся в клинике «Баланс Дент» (Москва, ул. Сивашская, 7, корп. 1).

- **Сайт:** HTML5 + CSS + JavaScript, без фреймворков. Хостинг — GitHub Pages.
- **Данные:** Google Таблица «Учет». Сайт общается с ней через Google Apps Script.

## Что где лежит

```
index.html          главная: врачи, услуги и цены, контакты
booking.html        онлайн-запись по свободным слотам
admin/index.html    вход для персонала и кабинет
css/style.css       общие стили и цвета сайта
css/booking.css     стили страницы записи
css/admin.css       стили кабинета
js/config.js        НАСТРОЙКИ: адрес Apps Script, врачи, запасной прайс
js/api.js           связь с Google Таблицей (и демо-режим)
js/main.js          логика главной
js/booking.js       логика записи
js/admin.js         логика кабинета
apps-script/        код для Google Apps Script + инструкция
img/                фото врачей и кабинета (yulia.jpg, tikhon.jpg)
CONTRACT.md         договорённости о структуре и API
```

## Демо-режим

Пока в `js/config.js` пустой `API_URL`, сайт работает на выдуманных данных:
запись «как будто» проходит, в кабинет можно войти с паролем `demo`.

## Как запустить у себя

1. Открыть папку в VS Code.
2. Правой кнопкой по `index.html` → **Open with Live Server**.

## Как подключить Google Таблицу

Пошагово — в [apps-script/README.md](apps-script/README.md).
Коротко: вставить `apps-script/Code.gs` в Apps Script таблицы, задать пароль
персонала в свойствах скрипта, опубликовать как веб-приложение и вставить
ссылку `/exec` в `js/config.js`.

## Как опубликовать изменения

В VS Code: Source Control → сообщение → **Commit** → **Sync Changes**.
Через минуту изменения появятся на `https://<логин>.github.io/<репозиторий>/`.

## Важно

Репозиторий публичный. Никогда не добавляйте сюда пароли, ссылки с паролями
и данные пациентов — они живут только в Google Таблице.
